# MenuPlanner — 献立アプリ

家族の献立を考えるための静的Webアプリです。サーバーやデータベースは使わず、データはすべて
端末のブラウザ内（localStorage）に保存されます。AIへの質問はコピー＆ペースト方式で、
お好きなAIツール（ChatGPT・Claudeなど）に貼り付けて使います。

## できること

| ページ | 内容 |
|---|---|
| トップ (`/index.html`) | 食べたいものメモ、今週の予定（日ごとに晩ごはんにいる家族を選択）、今ある食材、AIへの質問文の作成・読み込み、副菜の提案、買う食材リスト（カテゴリ別自動集計・推定予算・未購入分だけ共有）、結果・メモ、データのバックアップ（書き出し・取り込み） |
| 家族構成 (`/family.html`) | 家族の登録・並び替え・削除。子どもは年齢層を設定でき、AIが考える食材の分量に反映される |
| 苦手な食材・アレルギー (`/dislikes.html`) | アレルギー（安全重視・対象期間中は無条件で除外）と苦手な食材（任意で期限付き・期限切れで自動的に対象外）を別枠で管理。それぞれ対象の家族を選べる |
| 調味料マスタ (`/pantry.html`) | 家にある調味料にチェックを付けると、買う食材リストから自動で除外される |
| 献立リスト (`/menus.html`) | 保存した献立（期間＋中身のスナップショット）の一覧。保存した献立と感想をもとに「好みと傾向」をAIに分析してもらう機能 |

## 必要な準備

特にありません。アカウント登録・APIキー・サーバーのどれも不要です。GitHub Pagesなどの
静的ホスティングに置くだけで動きます。

## ローカルで動かす

`index.html` をブラウザで直接開くだけで動きます。Service Workerの挙動まで確認したい場合は、
ローカルサーバー経由で開いてください。

```bash
python3 -m http.server 8000
```

<http://localhost:8000> を開いてください。

## デプロイする場合

GitHub Pagesへのデプロイは `.github/workflows/deploy-pages.yml` が担っています。対象ブランチに
pushすると自動でビルド・公開されます。他のホスティング先でも、リポジトリの中身をそのまま
配信すれば動きます（ビルドステップ不要）。

## データの扱い方について（仕様の注意）

- データはすべて `localStorage` に保存され、キーはすべて `menuApp.` で始まります。バックアップの
  書き出し・取り込みは、この接頭辞を持つキーだけを対象にしています。
- 「今週の予定」は、週固定ではなく「開始日＿終了日」をキーにした期間として管理しています。
  開始日・終了日をわずかに動かした（境界の微調整）場合は、紐づく「追加した物」「副菜」
  「結果・メモ」「購入チェック」を前のキーから新しいキーへ引き継ぎます。「前の期間／次の期間」
  ボタンで別の期間へ移動する場合は引き継ぎません（元の期間のデータをそのまま残すため）。
- 食材名は `js/app.js` の `INGREDIENT_SYNONYMS` で表記ゆれ（しょうゆ／醤油など）を吸収し、
  代表名にまとめてから集計・在庫照合を行います。
- 「今ある食材」の在庫は、単位が一致して量が読み取れる場合だけ必要量から差し引きます。
  比べられない場合は、買い忘れを防ぐため安全側（全量を買う食材リストに残す）に倒します。
- アレルギー・苦手食材の確認は、料理名・食材名の文字列部分一致による簡易チェックです
  （`findSafetyMatches`）。完璧な判定ではないため、実際に使う前に必ず人の目で確認する前提です。
- 「献立リストへの保存」は、期間（開始日・終了日）のブックマークに加えて、保存した時点の
  献立・副菜の中身もスナップショットとして一緒に保持します。保存済みの献立を開くと、
  その時点の中身に復元されます（同じ日付でAIの献立を読み込み直していても上書きされません）。
- AIへの質問はコピー＆ペースト方式です。特定のAIサービス専用の機能は使っていないので、
  JSON形式で答えられるAIツールであれば基本的に使えます。返事の読み込み（`extractJson`）は、
  コードブロックでの囲み・前置きの文章・末尾の余分なカンマなど、形式のブレにある程度耐性があります。

## 技術構成

- HTML + CSS + JavaScript のみ。フレームワーク・ビルドツールなし
- データ保存：ブラウザの `localStorage` のみ（サーバーなし）
- PWA対応：`manifest.json` + Service Worker（`sw.js`。ネットワーク優先で取得し、電波が弱いときは
  3秒でキャッシュにフォールバック）

主なコード：

- `js/shared.js` — 複数ページ共通のデータ読み書き（家族構成・調味料マスタ・アレルギー・
  苦手な食材・献立・副菜・保存した献立）
- `js/app.js` — トップ画面のロジック（質問文の生成、AIの返事の読み込み・安全チェック、
  買う食材リストの集計、データのバックアップ）
- `js/family.js` / `js/dislikes.js` / `js/pantry.js` / `js/menus.js` — 各ページ固有の画面表示
- `css/style.css` — 全ページ共通のスタイル
- `sw.js` — Service Worker
